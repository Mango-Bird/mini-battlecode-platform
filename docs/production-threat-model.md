# Production threat model — Phase 11A

Scope: Internet attacker, malicious authenticated account/bot, compromised execution guest, lost worker/API/DB connection and operator error. Assets: source privacy, sessions, database, host integrity, availability, frozen results and rating ledger. API, guest, supervisor, database and CI identities are separate trust boundaries in the target architecture. Current local verification is insufficient to trust an Internet execution service. Severity below is residual **before** production remediation, not a claim of exploitable bypass in the local-only product.

| Threat / attack surface | Impact | Existing mitigation / source evidence | Missing production control | Residual risk | Required verification |
|---|---|---|---|---|---|
| Arbitrary JS / submitted source | Code execution outside game contract | BotSubmission strict32KiB/version/hash; VerifiedWorkerRunner gate; fresh QuickJS guest | Remote attested isolated worker and admission adapter | Critical | Malicious corpus in target runtime, no API-process execution |
| Sandbox escape / JS engine native bugs | Guest privilege escalation | QuickJS pinned build, module/capability denials; worker probes | MicroVM boundary, patch/image provenance and independent review | Critical; no absolute sandbox safety | Escape regression suite, host/network denial evidence, security review |
| Container breakout / supervisor Docker authority | Host takeover | nonroot readonly guest, cap-drop, no-new-privileges, no mounts | Separate worker host/identity, microVM or reviewed gVisor, no API-host Docker authority | Critical | Linux provider runtime/kernel/cgroup tests and incident isolation drill |
| CPU/RAM/PID/output exhaustion | Worker/API unavailable | worker.py quotas/deadlines/output limits; bounded local execution | Fleet admission/quota, isolated control plane, bounded durable queue | High | Saturation/cleanup tests on deployment hardware; limit fairness |
| Network exfiltration / guest | Source/secret theft, scanning | --network none, denied JS network | Host egress deny and authenticated allowlisted control plane, metadata service block | Critical | DNS/IPv4/IPv6/metadata probes and packet policy evidence |
| Host filesystem / guest or upload | Host file theft/overwrite | scratch readonly guest, no mounts, static source bounds | Ephemeral encrypted scratch, no host paths, service identity separation | High | Path traversal, symlink, fd inheritance and temp cleanup tests |
| DB credential theft / env/log/worker | Data compromise | Java supervisor clears env; guest no credentials; generic errors | Secret manager, API-only DB path, role separation, rotation | Critical | Guest/process env/log inspection with canaries; rotate/revoke drill |
| Session hijack / cookie/token/log | Account/source theft | opaque hashed sessions, bcrypt, expiry/revoke; AuthService | HTTPS Secure host cookie, XSS policy, rotation and log redaction coverage | High | Real HTTPS browser auth/session expiry/logout tests |
| CSRF/CORS / cross-origin API | Unauthorized mutation | exact local Origin+Host allowlist, Strict HttpOnly cookie, JSON requests | Production session-bound CSRF token, explicit HTTPS origins/proxy policy | High | Local HTTP negative tests pass; staging cross-site cookies/CSRF **NOT TESTED** |
| Cross-account authorization / identifiers | Source/version/result leakage or edits | PostgresSubmissionRepository owner checks; CompetitiveReadService entitlement; no nickname auth | Full production route inventory and admin least privilege | High | Existing owner/privacy IT plus staging IDOR matrix for every resource |
| Ranked/Elo manipulation / crafted result or duplicate | Rating corruption | frozen owner/version/hash, policy/mode checks, immutable unique ledger; RatingService | Authenticated fenced worker result and durable admission/outbox | High | Concurrent duplicate/conflict IT, forged/stale worker result and crash-commit tests |
| Queue flooding / join/cancel/signup | Capacity starvation, abuse | active unique owner/bot, queue rate bounds/cooldown, bounded local users | Distributed edge/account limits, anti-Sybil review, fleet quotas | High | Proxy spoof/rate/saturation tests, fairness and oldest-age metrics |
| Replay/source leakage / snapshots/profile/log | Opponent source/secret observation disclosure | sanitized view, participant authorization, bounded page/read serializer | Production logs/cache access and end-to-end privacy audit | High | CompetitiveReadPostgresIT plus staging cache/log/source canaries |
| Denial of service / HTTP/DB serialization | Thread/pool/storage exhaustion | HttpServer4 threads/queue16, request constraints, timeouts;4MiB response guard | Edge byte/rate limits; streaming response cap before serialization; DB pool/retention | High | Oversize/slow client/load tests; heap and connection budget |
| Worker crash/restart / lost response | Incorrect forfeit, duplicate game/rating | fail-closed gate; local recovery interrupts unknown attempt; no blind rerun | Durable claim epochs/heartbeats/reconcile and authenticated cancellation | High | Existing restart IT; target worker death, lease-loss and delayed completion tests |
| Malicious source upload / Unicode/JSON/metadata | Parser abuse, log/source leak, storage exhaustion | strict fields/JSON UTF-8,32KiB, immutable hash/version, no source logging intended | Production source quota/retention, security logging audit and dependency updates | High | Existing submission tests + target byte/UTF-8/fuzz limits |
| DB outage/restore/operator migration | Lost sessions/ledger divergence | transactions, FKs, Flyway checksums, lease | PITR/restore rehearsal, separate migration/runtime roles, bounded retries | High | Restore to isolated DB, ledger rebuild parity, RPO/RTO measurements |
| Supply chain / image/dependency/CI | Trusted binary compromise | pinned worker base/source hashes; Java dependency versions | SBOM, vulnerability triage, signed image/digest promotion and CI secrets policy | High | Reproducible provenance checks, scanning and rollback drill |

Current automated evidence: ProductionPreflightTest (unsafe declarations, secret-safe errors, local guard), PostgresPersistenceIT (sessions, CSRF/Origin/owner/versions/recovery), RankedPostgresIT (concurrent join/reserve, gate/limits/recovery), RatingPostgresIT (concurrent duplicate and rollback), CompetitiveReadPostgresIT (authorization/privacy/MVCC), PostgresWorkerIT (actual verified worker and durable games). These are regression checks, not penetration-test certification. No Phase8C.5 full security stress campaign or cloud sandbox review was run in Phase11A.

Release blocking order: separate execution boundary first; HTTPS auth/CSRF/proxy and secret/DB isolation next; durable lifecycle/restore/operational gates before admitting Internet bots. Any gate loss disables new ranked/tournament execution; safe read availability is a separate future concern. Infrastructure errors never automatically forfeit an innocent bot.
